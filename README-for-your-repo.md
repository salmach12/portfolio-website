# Salma Choukrallah — Portfolio

My personal website: a multi-page, hand-made site about who I am, what I build and what I love
(music, books, travel, film photography).

**Live site:** https://REPLACE-YOUR-SITE-URL

## What is inside

- **Code** — a small interactive terminal, my projects and my skills
- **Music** — vinyl records and a cassette that opens my playlist
- **Books / Films** — click-to-reveal bookshelf and a top-four films wall
- **Travel** — passport stamps that open into journal entries
- **Photos** — polaroid wall, camera roll and a scrolling film strip

## Built with

HTML, CSS and vanilla JavaScript (no frameworks, no build step). Fonts from Google Fonts.

## Run it locally

1. Download or clone the repository.
2. Open `index.html` in your browser. That's it.

(For a closer match to the live site you can also run `npx serve` inside the folder.)

## What I focused on

- Keyboard-friendly (every clickable card is a real button) and respects reduced-motion settings
- Responsive layout down to small phones
- Light pages: compressed, lazy-loaded images and a single shared script
